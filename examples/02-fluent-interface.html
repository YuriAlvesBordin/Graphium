02 · Fluent Interface

Method chaining for concise code. Graph methods return the graph, and per-node / per-link handles returned by node(id) and link(id) chain their own style calls.

addNode, link, setTheme, setPhysics… all return this, so setup reads as one sentence. node('id') and link('id') return handles whose methods (color, radius, label, fix, curve, dashed…) chain too.
