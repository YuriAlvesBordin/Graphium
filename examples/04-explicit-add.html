04 · Guarded Add (IfAbsent)

Preventing accidental overwrites. Graphium has no built-in addNodeIfAbsent; this page builds the guard on top of getNode/getLink, since addNode replaces an existing id and link(source, target) reuses the auto id.

Watch the log: guarded calls report skipped for known ids, blind calls silently replace them — note how the overwritten node keeps its old position but loses its custom radius and label.
