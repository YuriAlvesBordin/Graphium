09 · Export JSON

Exporting graph data as JSON — including the current layout. toJSON() returns the same { nodes, links } payload setData accepts, so exports round-trip: edit the graph, export, re-import.

// press “Export current layout” to serialize the graph

The export carries live x/y positions. “Reload JSON into graph” pushes the edited payload back through setData — the graph keeps its exact shape instead of re-flowing.
