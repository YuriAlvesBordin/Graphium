## Expected Outcome
- Library builds and runs without edge bundling functionality
- All edges render as straight lines (no bundling)
- Core features (physics layout, zooming, panning, clicking, dragging) remain intact
- No runtime errors related to missing bundling modules
- Bundle size slightly reduced due to removed code
- API is simplified (bundling-related methods/options removed)

## Backward Compatibility
- This is a breaking change for users who were using edge bundling API
- All other APIs remain unchanged
- Visual output for graphs with multiple edges between same nodes will change from bundled to straight lines (explicitly requested)
