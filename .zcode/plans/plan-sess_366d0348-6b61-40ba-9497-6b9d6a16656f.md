## Implementation Plan: ARIA Labels and Keyboard Navigation for Graphium

### Problem
Graphium currently lacks accessibility features - no ARIA labels on canvas elements and no keyboard navigation support, making it inaccessible to users who rely on screen readers or keyboard-only navigation.

### Solution
Implement ARIA labels, keyboard navigation, and live regions in Graphium while maintaining backward compatibility and performance.

### Implementation Details

#### 1. ARIA Label and Focus Management (in Graphium constructor)
```javascript
// After canvas assignment in constructor:
if (this.options.canvas) {
  // Set ARIA label if not already present (customizable via options)
  const ariaLabel = this.options.canvas.getAttribute('aria-label') || 
    this.options.accessibility?.label || 
    `Interactive graph visualization with ${this.options.nodeCapacity || 256} nodes`;
  
  if (!this.options.canvas.hasAttribute('aria-label')) {
    this.options.canvas.setAttribute('aria-label', ariaLabel);
  }
  
  // Make canvas focusable for keyboard interaction
  if (this.options.canvas.tabIndex === -1) {
    this.options.canvas.tabIndex = 0;
  }
  
  // Add live region for announcements
  this._setupAccessibilityFeatures();
}
```

#### 2. Keyboard Navigation Implementation
Add keyboard event handling in Graphium constructor:
```javascript
if (this.options.canvas && this.options.accessibility?.keyboard !== false) {
  this._bindKeyboardEvents();
}
```

Keyboard handler methods:
- Arrow keys: Pan view (left/right/up/down)
- +/- keys: Zoom in/out  
- Home: Fit to content
- Escape: Clear selection
- Enter/Space: Trigger click on focused element (if applicable)

#### 3. Accessibility Options
Add to DEFAULTS in Graphium.js:
```javascript
accessibility: {
  enabled: true,
  label: null, // Custom ARIA label
  keyboard: true, // Enable keyboard navigation
  liveRegion: true, // Enable live region announcements
  announcementDelay: 1000 // ms to wait before announcing layout stability
}
```

#### 4. Live Region for Announcements
```javascript
_setupAccessibilityFeatures() {
  if (!this.options.accessibility?.liveRegion) return;
  
  this.liveRegion = document.createElement('div');
  this.liveRegion.setAttribute('aria-live', 'polite');
  this.liveRegion.setAttribute('aria-atomic', 'true');
  this.liveRegion.style.position = 'fixed';
  this.liveRegion.style.width = '1px';
  this.liveRegion.style.height = '1px';
  this.liveRegion.style.overflow = 'hidden';
  this.labelContainer.appendChild(this.liveRegion);
}

// Example usage in physics step:
_announceLayoutStable() {
  if (!this.liveRegion) return;
  this.liveRegion.textContent = `Graph layout stabilized`;
  // Clear after delay to prevent screen reader repetition
  setTimeout(() => { this.liveRegion.textContent = ''; }, this.options.accessibility?.announcementDelay || 1000);
}
```

#### 5. Event Integration
- Extend existing event system to emit keyboard events
- Forward keyboard events similar to pointer events
- Emit custom events like `'pan'`, `'zoom'` from keyboard handlers

- All features opt-in via `options.accessibility` 
- Default behavior unchanged when accessibility options not specified
- No performance impact when features disabled
- Existing API remains intact
