The issue is that edge bundling in Graph2D only activates when there are 8 or more nodes due to the thresholdNodes default value being set to 8 in EdgeBundling2D.js. This prevents bundling from working for smaller graphs (3-7 nodes) as reported by the user.

**Root Cause:**
In /home/yuri/Code/JS/Graph2D/src/physics/EdgeBundling2D.js, line 17:
```javascript
thresholdNodes: 8,
```
And line 384 in the rebuild() method:
```javascript
if (this.model.nodeCount >= this.options.thresholdNodes) {
  this._applyBundling();
}
```
When nodeCount < thresholdNodes, _applyBundling() is skipped, so edges are rendered as straight lines (with only basic smoothing and node avoidance) instead of following bundled routes.

**Solution:**
Change the default thresholdNodes value from 8 to 3, which will allow edge bundling to activate for graphs with 3 or more nodes, matching the user's expectation of "3 nós ou mais conectados entre si".

**Changes Required:**

1. **Modify EdgeBundling2D.js:**
   - Change line 17 from `thresholdNodes: 8,` to `thresholdNodes: 3,`

2. **Update Documentation:**
   - In /home/yuri/Code/JS/Graph2D/docs/api-reference.md line 46:
     Change `thresholdNodes?: number;          // default: 8` 
     to `thresholdNodes?: number;          // default: 3`
   - In /home/yuri/Code/JS/Graph2D/docs/bundling.md:
     Change `thresholdNodes: 8,              // Min nodes before bundling activates`
     to `thresholdNodes: 3,              // Min nodes before bundling activates`

**Test Scenarios to Verify:**
- 2-node graph: Should not bundle (insufficient edges for meaningful bundling)
- 3-node triangle (3 edges): Should now bundle (previously did not)
- 3-node line (2 edges): Should bundle if edges are compatible
- 7-node graph: Should now bundle (previously did not, as 7 < 8)
- 8+ node graph: Should continue to bundle (no change in behavior)

**Impact:**
This change is backward-compatible for graphs with 8+ nodes (they will continue to bundle as before). For graphs with 3-7 nodes, bundling will now activate where it previously did not, providing the expected bundled edge rendering instead of straight lines.
